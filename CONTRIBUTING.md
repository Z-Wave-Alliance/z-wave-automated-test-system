# Contributing

All types of contributions are encouraged and valued. 

Contributions are welcome in the form of pull requests.
All incoming pull requests should be tested on the developer's own fork beforehand.

# Guidelines

Reading existing documents might help to get your contribution smoothly accepted:

https://github.com/Z-Wave-Alliance/open-source-working-group

# Testing code

To test your code, create a fork of this repository and enable GitHub Actions on it.
The workflows need no secrets, so the build and the tests run on the fork as they are.
